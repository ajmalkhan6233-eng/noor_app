# noor Visual Reference Analysis

## The capability, done safely
Claude can analyze images directly and extract real design/UX
patterns from them — this has worked repeatedly on this project (the
particle-effect reference videos, the islamtics ad, the Athan app
screenshots all led to real, useful, adopted ideas).

The reliable way to reference a video or social post: **screenshot the
specific moment(s) that show what's interesting**, and share those
images directly. A few frames from a video usually captures the
actual design idea (a transition, a layout, a color treatment) just
as well as the full video would.

## Why not a video-downloading/scraping tool
Tools that claim to fetch and analyze arbitrary social media video
content typically work by scraping or downloading — usually against
that platform's own terms of service, and from unverified sources
running unknown code, that's a real risk with no upside noor actually
needs. Screenshots avoid all of this: no scraping, no ToS risk, no
unverified installer, and the actual design idea comes through just
as clearly.

## What to extract from a reference (same discipline as competitor research)
- The *pattern* (a motion idea, a layout, a color treatment, an
  interaction) — not literal assets, colors, or copyrighted content.
- Translate into noor's own locked design language
  (noor-design-system) rather than copying the source's exact look.
- If the reference is a competitor app specifically, also apply
  noor-scope-discipline — a good pattern is still just a suggestion
  to report back, not something to silently build in.
